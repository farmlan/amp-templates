How to join

  1. Launch the clientOpen Spellbreak Community Version on your PC.
  2. Enter the server addressWhen asked for a server, type 192.168.5.15:7777 with the colon.
  3. Wait in the lobbyThe match starts once enough mages connect. Hang tight.

Good to know

  1. LAN onlyYou need to be on the FarmLAN network. No port forwarding or internet needed.
  2. Can't connect?Check the status light up top. If it isn't green, the server is starting or switching modes. Give it a minute.
  3. Wrong mode?Ask an admin. They can switch between Solo, Duo, Squad and Dominion in a few seconds.
